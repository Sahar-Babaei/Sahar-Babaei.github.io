Section Library

A working reference of reusable case study section layouts. Every pattern below uses the exact same "vu-" classes that the real case study pages use — copy the markup straight into a new case study and it'll just work, no separate stylesheet involved. Each block names what it's for and, where relevant, which live page already uses it.

Hero

There is one canonical hero for the whole site — reuse it as-is rather than inventing a new one. Full markup reference: any real case study page, or casestudy-template.html.

Twelve patterns built specifically so a reader can follow a case study's story by skimming — bold lines, icons, and short rows that don't require reading every paragraph to get the gist.
